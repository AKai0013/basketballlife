# 🏀 BasketballLife｜V7.49.8

**BasketballLife** 是一款以瀏覽器遊玩的籃球生涯模擬遊戲。

你將從 **16 歲、高一、HBL** 開始自己的籃球人生。  
選擇位置、取得世界種子，經歷訓練、比賽、傷病、轉學、職業合約、交易、國家隊與人生事件，直到球員生涯正式落幕。

每一輪人生都可能完全不同。

# 🧬 世界種子

每次建立球員時都會取得一組 **8 碼世界種子 Seed**。

Seed 由英文字母與數字組成，共有約 **36⁸＝2,821,109,907,456（約 2.8 兆）種組合**，不再受限於原本的固定 50 組種子庫。

世界種子會影響球員的隱藏先天條件，包括：

- 初始能力
- 自然天賦線
- 成長速度
- 部分隱藏身體與個性特質
- 生涯中的固定隨機結果

相同的 Seed 搭配相同位置，仍會形成一致的球員先天條件與固定隨機結果，方便玩家重玩、交換 Seed 或比較不同養成路線。

早期版本的原始 50 組 Seed 仍完整保留原本的等級與行為，舊存檔及舊 Seed 不會因種子庫擴充而改變。

### Seed 隱藏等級

| 等級 | 約略比例 | 大致定位 |
|---|---:|---|
| 👑 S+ 傳奇 | 6% | 世代級天賦，有機會挑戰最高舞台 |
| ⭐ S 頂尖 | 14% | 頂級旅外與 NBA 挑戰級潛力 |
| 🔥 A 優秀 | 24% | 職業明星、穩定旅外等級 |
| 🏀 B 普通 | 36% | 最常見的正常球員生涯 |
| 🎲 C 苦命 | 20% | 天賦較有限，但仍有逆襲可能 |

> Seed 等級不會決定一切。  
> S+ 也可能因傷病與錯誤選擇跌落神壇；C 級也可能靠天才覺醒、突破天賦線與正確生涯決策完成逆襲。

為保留探索樂趣，本 README **不公開每一組 Seed 對應的隱藏等級**。

# 📊 八項能力

球員共有八項主要能力：

- 投射
- 終結
- 控球
- 傳球
- 防守
- 籃板
- 體能
- 球商

**99 為單項能力的絕對上限。**

每位球員另外都有自己的「自然天賦線」。

自然天賦線 **不是硬上限**。  
能力超過天賦線後仍可以繼續成長，但訓練效率與能力點成本會逐漸提高。

因此：

> 天賦決定你走得多輕鬆，並不完全決定你最後能走多遠。

# 🎲 季初特訓與天才覺醒

每季開始會進行自主訓練並擲出訓練骰。

進入特訓頁面後，骰子會先呈現翻滾、落桌，再依序揭曉數字；所有骰子揭曉前不能分配。若裝置啟用「減少動態效果」，系統會直接顯示結果。

骰子數量會隨年齡下降：

- 22 歲以前：4～6 顆
- 22 歲以上：3～6 顆

每顆骰子的點數就是實際訓練點數，**不再套用年齡吸收倍率**：不論幾歲，擲出 6 就是 6 點。

每項能力的下一級都會明確顯示：

- 從目前數值升到下一級共需幾點
- 已累積多少進度
- 還差幾點
- 基礎成本與突破天賦線的額外成本

骰子點數不足時不會浪費，進度會保留到之後的骰子或未來賽季。能力越高，升級成本越高；超過自然天賦線後，還會增加突破成本。季末獲得的能力點也使用相同成本規則，並可返回上一步重新分配。

年輕球員通常仍成長較快，原因是能力值較低、升級成本較便宜，且 22 歲前至少會有 4 顆訓練骰；並不是因為同一顆骰子在年輕時被額外放大。

### ✨ 隱藏天才系統

如果球員在 **22 歲以前累積擲出 5 次「6」**，將完成潛能覺醒。

可能覺醒：

- 得分天才
- 控場天才
- 攻防怪物
- 運動天才
- 大心臟王牌

不同天才類型會強化不同能力的天賦線。

22 歲前若未完成條件，該輪生涯的天才覺醒路線將關閉。

# 🎓 職涯發展

所有球員從：

**HBL 高中籃球**

開始。

高中畢業後，依照：

- 綜合能力
- 自然天賦
- 高中比賽表現
- 球探評級
- 傷病履歷
- 隱藏潛力

決定可能出現的下一步。

系統會依條件產生實際邀請，**有收到的路線才會出現在選項中，並由玩家自行選擇**；不是高中畢業後由系統固定分配唯一去向。

### 大專／海外升學

可能路線包括：

**HBL**
→ UBA  
→ UBA 強權  
→ NJCAA  
→ 日本大學  
→ NCAA

其中 **UBA 是最穩定的升學路線**，其他海外邀請則需要一定球探評價，並帶有 Seed 決定的邀請差異。

### 🇺🇸 NJCAA 路線

NJCAA 是兩年制大學，也是重要的美國籃球跳板。

兩年完成後可以選擇：

- 轉學 NCAA
- 回台轉入 UBA
- 轉入 UBA 強權
- 轉往日本大學
- 直接投入職業市場

轉往四年制大學後會以 **大三身分續讀**，不需要重新從大一開始。

如果 NJCAA 第一年表現非常突出，也可能提前取得 NCAA 轉學機會。

換句話說，選擇 NJCAA 不代表兩年後只能回台；NCAA 仍是正式的後續選項，只是需要符合當時的表現與邀請條件。

### 巔峰、退化與老將上場時間

- **24～30 歲**是主要巔峰區間。

# 🏥 傷病系統

傷病不是單純固定機率。

每次事件的受傷風險會依據：

- 耐久度
- 疲勞
- 身體負荷
- 最近三年傷病
- 舊傷
- 年齡
- 球季策略
- 特殊稱號
- 復健與醫療保護

動態計算。

### 一般健康球員

一般健康狀態下，單次事件的受傷風險通常約：

**2%～4%**

一般事件的底層風險最低約 **1%**；極端高負荷、疲勞與舊傷累積時，單次事件風險最高可能接近 **28%**。

選擇「全力衝刺」、長期高負荷、累積舊傷與年齡增長，都會提高風險。

### 傷勢嚴重度

在一般低負荷狀態下，若真的發生傷病，傷勢大致分布：

| 傷勢 | 約略比例 |
|---|---:|
| 輕傷 | 約 66.5% |
| 中傷 | 約 28.5% |
| 大傷 | 約 4.1% |
| 重傷 | 約 0.9% |

這些比例並非固定。

身體負荷、年齡、近年傷病與舊傷越高，中傷、大傷與重傷機率也會提高。

可能出現的傷勢包括：

**輕傷**
- 手指挫傷
- 一般腳踝扭傷
- 大腿前側拉傷
- 肩部拉傷

**中傷**
- 高位腳踝扭傷
- 腿後肌拉傷
- 腹股溝拉傷
- 下背傷勢
- MCL 扭傷
- 腦震盪

**大傷**
- 半月板撕裂
- 嚴重腳踝韌帶撕裂
- 足部應力性骨折
- 髕腱重度傷勢

**重傷**
- ACL 撕裂
- 阿基里斯腱斷裂
- 髕腱斷裂

重傷可能造成長期能力損失、缺席大量比賽，甚至直接改變整條職業生涯。

手術與完整復健則能提供後續醫療保護，降低短期內大傷、重傷與同部位復發的機率。

# 🏛️ 退休與歷史地位

生涯終結並不只是「Game Over」。

退休後會產生完整的 **COURT LEGACY 生涯終章**，統計：

- 生涯總場次
- 巔峰 OVR
- 各聯盟生涯數據
- 生涯收入
- 冠軍
- MVP / FMVP / DPOY
- 一陣與明星賽
- 各項數據王
- 國家隊
- 生涯稱號
- 名人堂票選
- 球衣退休
- 世界種子真實等級
- 完整逐季紀錄

依據球員實際履歷，退休方式也可能不同：

- 正式引退之夜
- 最後一戰
- 安靜離開職業市場

不是每名球員都一定會獲得巨星級退休待遇。

當市場與身體狀況準備迫使球員退休時，不會再一律於賽季結束後直接跳到退休頁。玩家可能面臨 **生涯續命抉擇**：

- **接受退場**：保留目前名聲與生涯評價，正式結算退休。
- **回家鄉最後一舞**：接受降薪與限時輪替，取得 1 年告別合約，球季結束後正式退休。
- **拒絕退場、逼球團留人**：公開施壓並參加測試，有機會取得 1 年老將證明約；無論成功與否都會傷害球隊信任與市場評價，並得到負面稱號「休息室毒瘤」。

退休頁採用全新的生涯終章版面：左側整理高中、大學、職業到退休的完整軌跡；右側顯示球員抬頭、BL POWER、巔峰 OVR 與引退 OVR，並依生涯路線、榮譽、效力球隊與退場方式生成不同的球迷回聲。

### 排行榜登錄與公開生涯

退休頁會先請玩家選擇：

- **🏆 登錄並查看排名**
- **只保留在本機**

開始下一段人生前必須完成其中一項選擇，避免玩家忘記登錄而讓排行榜缺少生涯資料。

登錄時只會公開玩家暱稱、球員履歷與生涯數據，不會公開個人資料。登錄成功後會立即顯示該生涯的 **BL POWER 排名**與**巔峰 OVR 排名**，之後才另外提供「分享生涯連結」；分享是額外選項，不會自動發布到社群。

選擇只保留在本機後，該生涯不會出現在排行榜，也不會產生對外分享，但仍可在退休頁改為登錄。
