# BasketballLife V8.0 — 我的球員、我的故事

從 HBL 出發，經歷升學、職業、旅外、國家隊、傷病、合約與場外人生，直到正式退休的籃球生涯模擬器。

## V8.0 正式更新

- 事件選擇不再提前公布成功率或標準答案；校園、職業與醫療事件改為真正的取捨。
- 加入隊友風波、洋將離隊、更衣室分派及更多場外事件。
- 強化疲勞、舊傷、大傷、手術、打針與帶傷上場的收益及後果。
- 64 位完整插畫人物；每段生涯維持同一張可辨識的臉，不再混搭臉型與髮型。
- 背號、慣用手、出生地與依生涯階段變化的實際球隊角色。
- 教練、經紀人、隊友、宿敵與伴侶會建立持續關係；經紀人只會在職業階段登場。
- 球隊具有爭冠、重建、換教練與財務壓力；合約包含角色承諾、球員選項與球隊選項。
- 跨年度連鎖後果與退休專題，只保留 3–5 個真正重要的生涯轉折。
- 標準、大字、精簡三種閱讀模式，並完成手機版選項與長內容防遮蔽修正。
- 合約到期可主動退休；拒絕單一合約不會立刻結束生涯，老將也不再固定於 42 歲強制退休。

## 排行榜

- **V8 現役榜**：只收錄 V8 正式版的一般公開生涯。
- **每週 Seed 挑戰榜**：官方固定 Seed、位置、身高與臂展；同一玩家每週只保留 BL POWER 最高的一支生涯。
- **V7 傳奇榜**：永久保留既有 V7.50 公開生涯。
- 每週挑戰結束後，冠軍及代表生涯會保留在歷屆紀錄。

部署 V8 前，請先在 Supabase SQL Editor 執行 [supabase_v8_release.sql](./supabase_v8_release.sql)，再部署 `index.html`、`assets/` 與其餘靜態檔案。
