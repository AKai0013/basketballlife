# BasketballLife V8.0

一款以台灣籃球為起點的文字生涯模擬器。

你會從 16 歲的 HBL 球員出發，經歷升學、選秀、職業聯賽、旅外、國家隊、傷病、合約與場外人生，直到決定何時離開球場。相同的天賦與體質，也可能因為每一次選擇走出完全不同的生涯。

**正式遊戲：<https://basketballlife.pages.dev/>**

## 遊戲特色

- 從 HBL、大專籃球一路挑戰台灣職籃、日本、韓國、CBA、NBA G League 與 NBA。
- 五種場上位置、身高與臂展、慣用手、背號、出生地及 64 位完整球員外觀。
- 先發、板凳、第六人、球隊核心等角色會隨表現、球隊需求與合約承諾改變。
- 一般事件、特殊事件、場外事件與醫療壓力事件都具有收益與代價，不預先公布標準答案。
- 疲勞、舊傷、重大傷勢、手術、打針、限時上場與帶傷硬撐會實際影響出賽、生涯長度與市場評價。
- 教練、經紀人、隊友、宿敵與伴侶關係會延續，不是事件結束就消失。
- 球隊會經歷爭冠、重建、換教練與財務壓力；合約包含角色承諾、球員選項與球隊選項。
- 退休後產生完整生涯專題與中文紀念海報，回顧效力球隊、聯盟成績、榮譽、國家隊及重要轉折。

## 如何遊玩

1. 輸入球員姓名並選擇位置、身材、背號、慣用手、出生地與外觀。
2. 使用隨機 Seed 開始一般生涯，或參加官方每週 Seed 挑戰。
3. 每季完成訓練、事件、健康管理、賽季結算與能力點分配。
4. 進入職業後處理球隊角色、合約、自由市場、旅外及國家隊機會。
5. 在合約到期或生涯後期自行決定續戰或退休。

遊戲存檔保存在玩家目前使用的瀏覽器裝置。清除瀏覽器網站資料前，請先完成想保留的生涯並上傳公開紀錄。

## V8.0「我的球員、我的故事」

- 事件選擇不再提前公開成功率、冒險／平衡／穩健標籤或紅黃綠答案提示。
- 重寫校園與職業事件，新增隊友風波、洋將離隊、更衣室分派、酒駕、博弈接觸等場外事件。
- 強化傷病部位對應、疲勞累積、重大傷勢與復出選擇。
- 加入 64 位完整插畫人物，選定後會跟隨整段生涯。
- 加入會延續的角色關係、球隊方向、角色承諾及跨年度後果。
- 重做事件、健康、賽季結算、公開生涯、退休頁與退休紀念海報。
- 加入標準、大字、精簡三種閱讀模式，並改善桌面與手機版操作。
- 合約到期可主動退休；拒絕單一報價不會立刻結束生涯，也不再固定於 42 歲強制退休。

## 排行榜與每週 Seed

- **V8 現役榜**：V8 正式版的一般公開生涯。
- **每週 Seed 挑戰榜**：所有玩家使用相同 Seed、位置與身材條件；每位玩家每週只保留最高成績。
- **V7 傳奇榜**：永久保留 V7.50 時期已公開的生涯，不會被 V8 紀錄覆蓋。
- 每週挑戰結束後，冠軍與代表生涯會收入歷屆紀錄。
- 排行榜顯示前 50 名；上方玩家數與公開生涯數則統計資料庫內的全部紀錄。

公開排行榜目前使用 Cloudflare Pages Functions 與 D1。排行榜採按需讀取與短期快取，不建立常駐即時監聽；完整生涯只在玩家點開時載入，以降低不必要的流量。

## BL LIVE

BL LIVE 會播報公開生涯中的重要消息，包括頂級聯盟冠軍、MVP／DPOY、NBA 突破、成人國家隊重大成績、名人堂與傳奇里程碑。一般小事件不會佔據跑馬燈。

## 資料保留

- V7.50 的公開生涯已轉入 D1，並永久保留在「V7 傳奇榜」。
- V8 一般生涯與每週 Seed 生涯分開計算，不會互相覆蓋。
- 每週 Seed 生涯不寫入 V8 現役榜，只進入當週挑戰榜。
- 公開生涯只保存遊戲需要的資料；玩家自行上傳的圖片不會寫入排行榜資料庫。

## 本機測試

這是無需建置工具即可開啟的單頁遊戲。若要執行自動測試，需先安裝 Node.js：

```bash
node tests/v8_static_release_audit.js
node tests/v8_smoke_test.js
node tests/v8_actual_playthrough.js
```

D1 資料表定義位於 [`migrations/0001_basketballlife_d1.sql`](./migrations/0001_basketballlife_d1.sql)。Pages Functions 位於 [`functions/api/`](./functions/api/)。
