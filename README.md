# 🏀 BasketballLife

**BasketballLife** 是一款以瀏覽器遊玩的籃球生涯模擬遊戲。

你將從 **16 歲、高一、HBL** 開始自己的籃球人生。  
選擇位置、取得世界種子，經歷訓練、比賽、傷病、轉學、職業合約、交易、國家隊與人生事件，直到球員生涯正式落幕。

每一輪人生都可能完全不同。

🌐 遊戲網址：  
https://akai0013.github.io/basketballlife/

> ⚠️ 目前仍屬 Online Beta，遊戲平衡、數值與功能可能持續調整。

## 🎮 遊戲流程

每個賽季大致包含：

**季初特訓 → 一般事件 → 特殊事件 → 健康檢查 → 賽季結算 → 能力點分配 → 生涯抉擇**

玩家必須在成長、比賽表現、健康與生涯發展之間做選擇。

- 稱號與特殊事件
- 最終歷史地位

# 🧬 世界種子

每次建立球員時都會取得一組 **8 碼世界種子 Seed**。

目前共有 **50 組固定世界種子**。

世界種子會影響球員的隱藏先天條件，包括：

- 初始能力
- 自然天賦線
- 成長速度
- 部分隱藏身體與個性特質
- 生涯中的固定隨機結果

相同的 Seed 搭配相同位置，會形成具有一致性的球員先天條件。

### Seed 隱藏等級

| 等級 | 數量 | 出現比例 | 大致定位 |
|---|---:|---:|---|
| 👑 S+ 傳奇 | 3 / 50 | 6% | 世代級天賦，有機會挑戰最高舞台 |
| ⭐ S 頂尖 | 7 / 50 | 14% | 頂級旅外與 NBA 挑戰級潛力 |
| 🔥 A 優秀 | 12 / 50 | 24% | 職業明星、穩定旅外等級 |
| 🏀 B 普通 | 18 / 50 | 36% | 最常見的正常球員生涯 |
| 🎲 C 苦命 | 10 / 50 | 20% | 天賦較有限，但仍有逆襲可能 |

> Seed 等級不會決定一切。  
> S+ 也可能因傷病與錯誤選擇跌落神壇；C 級也可能靠天才覺醒、突破天賦線與正確生涯決策完成逆襲。

為保留探索樂趣，本 README **不公開每一組 Seed 對應的隱藏等級**。

# 📊 八項能力

球員共有八項主要能力：

- 投射
- 終結
- 控球
- 傳球
- 防守
- 籃板
- 體能
- 球商

**99 為單項能力的絕對上限。**

每位球員另外都有自己的「自然天賦線」。

自然天賦線 **不是硬上限**。  
能力超過天賦線後仍可以繼續成長，但訓練效率與能力點成本會逐漸提高。

因此：

> 天賦決定你走得多輕鬆，並不完全決定你最後能走多遠。

# 🎲 季初特訓

每季開始會進行自主訓練並擲出訓練骰。

骰子數量：

22歲以前：4～6顆
22歲以上：3～6顆

骰子的點數就是本次可投入的訓練點數，例如骰到「6」就獲得6點。

訓練升級與季末能力點使用相同的能力成長成本。能力越高，升級所需點數越多；超過自然天賦線後，突破成本也會進一步提高。

如果單顆骰子的剩餘點數不足以完成下一級，進度會保留在該能力，之後可繼續累積。

年輕球員通常仍較容易快速成長，主要是因為能力較低時升級成本較便宜，且22歲以前每季至少有4顆訓練骰。

### ✨ 隱藏天才系統

如果球員在 **22 歲以前累積擲出 5 次「6」**，將完成潛能覺醒。

可能覺醒：

- 得分天才
- 控場天才
- 攻防怪物
- 運動天才
- 大心臟王牌

不同天才類型會強化不同能力的天賦線。

22 歲前若未完成條件，該輪生涯的天才覺醒路線將關閉。

# 🎓 職涯發展

所有球員從：

**HBL 高中籃球**

開始。

高中畢業後，依照：

- 綜合能力
- 自然天賦
- 高中比賽表現
- 球探評級
- 傷病履歷
- 隱藏潛力

決定可能出現的下一步。

### 大專／海外升學

可能路線包括：

**HBL**
→ UBA  
→ UBA 強權  
→ NJCAA  
→ 日本大學  
→ NCAA

其中 **UBA 是最穩定的升學路線**，其他海外邀請則需要一定球探評價，並帶有 Seed 決定的邀請差異。

### 🇺🇸 NJCAA 路線

NJCAA 是兩年制大學，也是重要的美國籃球跳板。

兩年完成後可以選擇：

- 轉學 NCAA
- 回台轉入 UBA
- 轉入 UBA 強權
- 轉往日本大學
- 直接投入職業市場

轉往四年制大學後會以 **大三身分續讀**，不需要重新從大一開始。

如果 NJCAA 第一年表現非常突出，也可能提前取得 NCAA 轉學機會。

# 🏥 傷病系統

傷病不是單純固定機率。

每次事件的受傷風險會依據：

- 耐久度
- 疲勞
- 身體負荷
- 最近三年傷病
- 舊傷
- 年齡
- 球季策略
- 特殊稱號
- 復健與醫療保護

動態計算。

### 一般健康球員

一般健康狀態下，單次事件的受傷風險通常約：

**2%～4%**

一般事件的底層風險最低約 **1%**；極端高負荷、疲勞與舊傷累積時，單次事件風險最高可能接近 **28%**。

選擇「全力衝刺」、長期高負荷、累積舊傷與年齡增長，都會提高風險。

### 傷勢嚴重度

在一般低負荷狀態下，若真的發生傷病，傷勢大致分布：

| 傷勢 | 約略比例 |
|---|---:|
| 輕傷 | 約 66.5% |
| 中傷 | 約 28.5% |
| 大傷 | 約 4.1% |
| 重傷 | 約 0.9% |

這些比例並非固定。

身體負荷、年齡、近年傷病與舊傷越高，中傷、大傷與重傷機率也會提高。

可能出現的傷勢包括：

**輕傷**
- 手指挫傷
- 一般腳踝扭傷
- 大腿前側拉傷
- 肩部拉傷

**中傷**
- 高位腳踝扭傷
- 腿後肌拉傷
- 腹股溝拉傷
- 下背傷勢
- MCL 扭傷
- 腦震盪

**大傷**
- 半月板撕裂
- 嚴重腳踝韌帶撕裂
- 足部應力性骨折
- 髕腱重度傷勢

**重傷**
- ACL 撕裂
- 阿基里斯腱斷裂
- 髕腱斷裂

重傷可能造成長期能力損失、缺席大量比賽，甚至直接改變整條職業生涯。

手術與完整復健則能提供後續醫療保護，降低短期內大傷、重傷與同部位復發的機率。

- 生涯收入

- 國家隊
- 生涯稱號
- 名人堂票選
- 球衣退休
- 世界種子真實等級
- 完整逐季紀錄

依據球員實際履歷，退休方式也可能不同：

- 正式引退之夜
- 最後一戰
- 安靜離開職業市場

不是每名球員都一定會獲得巨星級退休待遇。
